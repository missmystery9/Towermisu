# TOWERMISU

A small browser-based stacking game.

## GitHub Pages setup

1. Create a new **Public** GitHub repository named `towermisu`.
2. Upload **index.html** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**.

After GitHub finishes deploying, your game will be available at:

`https://YOUR-USERNAME.github.io/towermisu/`

Replace `YOUR-USERNAME` with your GitHub username.

## Files

- `index.html` — the complete game. No build step, dependencies, or server required.
